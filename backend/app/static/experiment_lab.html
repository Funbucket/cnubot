현황은 15분마다 집계합니다. 관찰 완료는 마지막 분석 기준입니다. 이전 버튼 실험 기록

새 실험 설계 · 시작 전 검토

1. 결정할 문제
2. A/B 경험

A 현행 1개 / B 1만원 이하 간편식·간식/음료·생활용품 최대 3개. 같은 학식 빈자리, 하루 1회.

오늘 특가·먹거리·꿀템 직접 진입은 양쪽 모두 최대 6개입니다. 신규 카카오 발화 등록은 없습니다.

3. 대상과 배정

공통 적격 판정 후 사용자 단위 50:50. 개발자·QA·식별자 없는 요청 제외. 후보 부족·실패도 ITT에 유지합니다.

4. 지표와 안전성

개인별 168시간의 전체 상품 외부 클릭 사용자. Fisher exact + Newcombe-Wilson 95% CI. 활동일은 사전 14일·고정 θ Welch 비열등성.

5. 표본과 일정

모집 최대 28일 / 마지막 배정 뒤 168시간 관찰 / 수집 여유 24시간. 시작 후 고정됩니다.

6. 검토와 고정

미확정 항목은 비워서 초안으로 저장할 수 있습니다. 시작 게이트가 누락 항목을 안내합니다.
