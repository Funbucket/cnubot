개선하려는 항목을 펼쳐 확인하세요.

버튼 문구 어떤 문구가 상품 탐색으로 이어졌나요?

버튼 클릭률은 버튼 노출 사용자 기준입니다. 상품 클릭 사용자는 문구가 기록된 상품 카드 클릭의 개별 집계입니다.

$messages
상품 카드 배치 어느 위치에서 클릭이 발생했나요?

위치 정보가 기록된 카드만 포함합니다. 상품 구성과 노출량이 달라 위치 자체의 효과로 단정할 수 없습니다.

$positions
반복 노출 여러 번 보았을 때도 반응하나요?

선택 기간 내 사용자별 노출 순서입니다. 다음 노출 전까지 반응이 있었던 노출의 비율이며, 버튼 경유는 버튼 클릭, 바로 노출은 상품 클릭을 반응으로 봅니다. 마지막 노출은 선택 기간 종료까지 관찰합니다.

$fatigue
가드레일 · 학식 경험 광고 때문에 학식 사용이 줄지는 않았나요?

광고가 실린 응답만이 아니라 학식 사용 전체를 기준으로 봅니다. 다음날 재방문이 떨어지거나 1인당 조회가 줄면 노출을 줄여야 한다는 신호입니다. 다음날 데이터가 아직 없으면 집계 중, 그날 활동 기록이 통째로 없으면 측정 불가로 표시합니다.

지표를 읽는 방법
사용자 / 횟수
사용자는 중복 제거한 식별자 수, 횟수는 반복 행동을 포함한 이벤트 수입니다. 식별자가 없는 이벤트는 사용자 수에 포함되지 않습니다.
노출
챗봇 응답에 버튼이나 상품이 포함된 기록입니다. 사용자가 실제로 화면을 보았다는 보장은 없습니다.
클릭률
표시된 클릭 사용자 수를 해당 노출 사용자 수로 나눈 값입니다. 기간 밖 노출이나 기록 누락 때문에 100%를 넘을 수 있습니다.
집계 범위
서버에서 유효한 것으로 분류한 프로모션 이벤트를 집계하며 분석 제외 사용자 설정을 적용합니다. 경로·상품·날짜 간 사용자 수는 중복될 수 있습니다.
성과의 범위
상품 링크 클릭까지의 관심도를 보여줍니다. 구매·매출·구매 전환을 의미하지 않습니다.
