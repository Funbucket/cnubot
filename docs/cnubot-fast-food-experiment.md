# 먹거리 추천 24시간 탐색 A/B 운영 계획

- 설계·운영 변경일: 2026-10-13 KST
- 상태: 구현 후 고정 계획. 실제 시작 시각·ID·배정 수는 관리자 실험 이력으로 확인한다.
- 이 문서는 [먹거리 추천 실험 v2](cnubot-food-experiment-v2.md)의 다음 주 포트폴리오 일정에 맞춘 실행안이다. 처치 정의와 ITT 원칙은 이어받고, **주 지표·관찰 시간·모집 기간·안전성 보정값은 여기의 고정 계획을 우선**한다. 기존 A/A와 이전 미리보기 기록은 소급 변경하지 않는다.

## 가설과 경험

학식 상품 슬롯에서 기존 카테고리 순환 상품 1개(A) 대신, 표시 가격 1만원 이하의 서로 다른 먹거리 최대 3개(B)를 제공하면 배정 후 24시간 내 외부 상품 클릭 사용자 비율이 증가한다. B는 같은 슬롯의 가로 캐러셀이며 사용자별 KST 하루 최대 1회다. 직접 진입 상품 목록은 양쪽 모두 최대 6개다. 먹거리 분류의 `meal`에는 반찬도 포함될 수 있으므로 완성 식사·배송 포함 가격으로 설명하지 않는다.

고정 정책 식별자는 `student-food-v2`, 응답 기록 정책은 `student_food_bundle_v2`다. 상품 후보는 저장 스냅샷의 기존 유효 링크·재고·가격·학생 적합성·대용량 기준을 통과하고, 간편식/간식에서 서로 다른 품목군을 우선한다. 미노출 우선 → 오래전 노출 → 저가 → 리뷰 → 할인율 → ID 순이다. B 후보 2/1/0개면 각각 2/1개 또는 공통 판정 A 상품으로 대체하고, 모두 B 배정자로 분석한다. 표시 label은 `⚡️ 자취생 특가 · 1만원 이하 먹거리 · 제휴`, 외부 링크 버튼은 `구성·가격 확인`이다.

## 고정 관찰·판정

- 사용자 단위 50:50, 최초 공통 적격 배정. 개발자·QA·식별자 없는 요청 제외. 처치 상품 후보 수는 적격 판정에 쓰지 않는다.
- 주 지표: 최초 배정 시각부터 24시간 내 모든 상품 경로의 유효한 외부 클릭 사용자 / 전체 배정 사용자. 사용자당 1회만 센다. 24시간을 채운 배정자만 중간 참고 표에 넣는다. 관찰 중 이탈·B 후보 부족·응답 실패는 ITT 분모에 남긴다.
- 양측 Fisher exact α=.05, Newcombe-Wilson 95% CI. 큰 개선 신호: 관측 차이 ≥+1.0%p, CI 하한 >+0.5%p, Fisher p<.05. 이 기준은 사업적 제안값이며 손익분기점으로 입증되지 않았다.
- 안전성: 같은 24시간의 학식 이용 KST 날짜 수. 사전 14일 활동일로 고정 θ=.035454를 적용한 Welch 95% CI 하한이 -0.20일보다 높아야 한다. 24시간은 KST 날짜 2개에 걸칠 수 있다. 과거 24시간 활동과 사전 활동의 상관 약 .234로, 7일 실험의 약 40% 분산 감소를 이 계획에 대입하지 않는다.
- 운영 품질: 배정 SRM p<.001 조사, 중복 배정 없음, 응답·클릭 연결, QA 혼입 0, B 3개 확보율 목표 ≥90%, 군별 p95 ≤3,000ms, 오류·미완료 요청 조사. 카카오 스킬 제한 5초와 과거 A/A p95 약 1,385ms를 고려한 내부 한계다. 기준 미달 시 효과가 양수여도 품질 미결로 기록한다.
- 중간 효과로 조기 종료하지 않는다. 안전성·응답 장애의 운영상 중단은 사유를 기록한다. 탐색 목적이며 자동 확대 적용은 막는다.

## 표본과 기간

총 2,000명 또는 시작 후 9×24시간 중 먼저 도래할 때 신규 모집을 마감한다. 미달 시 자동 연장·목표 축소를 하지 않는다. 마지막 배정자 24시간 관찰과 추가 24시간 데이터 확인 후 최종 분석하므로 **시작 후 최대 약 11일**이다. 10월 14일까지 시작하면 계획상 10월 25일까지 결과를 확인할 수 있다. 실제 시작과 표본 도달이 달라지면 이 날짜를 보장하지 않는다.

시작 전 성숙 기준 자료: 2026-10-01~11 첫 인라인 노출 사용자 1,964명 중 24시간 유효 외부 클릭 7명, 약 0.3564%. 이 24시간 기준율은 기존 168시간 0.51%와 섞지 않는다. 사전 14일 활동일 평균 3.813, 24시간 활동일 평균 1.236, 고정 θ=.035454. 같은 1,964명에서 산출한 값이다. 총 2,000명에 대한 독립 배정 100,000회 시뮬레이션은 실제 +1.0%p에서 양의 유의성 약 66.3%, 큰 개선 신호 약 20.9%; 실제 +2.5%p에서 각각 약 99.8%·97.2%였다. 조건부 검정력이며 성공 가능성은 아니다. 7일 적격 고유 1,902명은 모집 가능성의 참고값이지 9일 2,000명 도달 보장이 아니다.

A/A는 미완료 상태에서 운영상 중단됐다. 시작 사유·품질 검증·계측 한계를 실험 이력에 적고, 결과를 탐색 신호로 해석한다. 다음 주 포트폴리오에는 시작·진행·최종 관찰 여부를 실제 시점대로 구분해 기록한다.

## 카카오 연결

새 발화나 스킬 URL은 없다. 정확한 기존 연결 예시:

| POST URL 예시 | 정확한 messageText | 역할 |
|---|---|---|
| `https://example.com/cafeteria/menu/day` | `월요일기숙사`, `화요일기숙사`, `수요일기숙사`, `목요일기숙사`, `금요일기숙사`, `토요일기숙사`, `일요일기숙사` | 기존 식단 조회의 빈 상품 슬롯에서 A/B 노출 |
| `https://example.com/promotions/collections/food` | `자취생 먹을거 핫딜` | `⚡️ 자취생 특가` 퀵리플라이·먹거리 직접 목록 |

위 경로는 구현 완료, 기존 카카오 등록을 사용한다. 다른 식당 발화는 [전체 등록표](kakao-message-routing.md)에 따르며 자동 매핑으로 가정하지 않는다. 상품의 `구성·가격 확인`은 webLink여서 messageText가 아니다. 학식·셔틀·학교혜택 최상위 메뉴는 독립으로 유지한다.

통계 방법 참고: [Statsig의 검정력 계획](https://docs.statsig.com/experiments/power-analysis), [Microsoft의 표본 적격 조건과 진단](https://www.microsoft.com/en-us/research/articles/diagnosing-sample-ratio-mismatch-in-a-b-testing/), [카카오 스킬 5초 제한](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/make_skill).
