# 중단된 A/A 품질 점검

점검: 2026-10-14 KST. 대상: 실험 #1 ‘학식 상품 추천 계측 검증 A/A’. 사용자 요청에 따라 **운영상 중단 상태를 유지**했다. 기존 1,353명 배정, 시작·중단 시각, 고정 계획, 오류 기록을 보존했다. 최신 점검 분석 #521을 공통 어드민의 해당 실험 상세에 저장했다. 수집 완전성을 승인하지 않았고 최종 판정 가능 여부도 false다.

## 결론

배정·동일 경험 제공·저장된 응답/노출 연결은 정상이다. 응답 오류 5건과 168시간 관찰 미완료로 **A/A 품질 통과를 선언할 수 없다**. 기존 품질 상태 ‘점검 필요’를 유지한다. 오류가 발생했다는 이유만으로 자동 중단됐던 실험은 아니며, 감사 이력상 중단 이유는 사용자의 별도 탐색 A/B 전환 요청이다.

## 클릭 계측

이 A/A 상품에서 실제 사용자가 발생시킨 서명 외부 클릭은 3건/3명이며 모두 B 배정 사용자다. 세 건 모두 선행 상품 제공 기록과 연결되고 클릭 필터 버전이 기록돼 있다. 별도 미리보기 클릭 1건은 분리했으며 품질 점검에 포함하지 않았다. 클릭이 적고 관찰 완료 사용자도 없으므로 군별 클릭 차이를 A/A 실패 증거로 해석하지 않는다.

주지표는 원래 ‘배정 후 168시간 동안의 전체 상품 외부 클릭 사용자’로 고정되어 있다. 현재 누적 집계에는 중단 이후 후속 실험 #2에서 발생한 클릭 사용자 A 1명/B 1명도 포함된다. 원래 지표를 임의로 A/A 상품 클릭만으로 변경하지 않는다. 앞으로 관찰창이 성숙하더라도, 후속 실험에 노출된 기간을 포함한 이 A/A 결과를 정상적으로 완주한 계측 검증 결과로 승인하면 안 된다.

## 오류·정책 점검의 한계

5건 모두 DB 오류 코드가 `request_failed`다. 기록 코드상 HTTP 400 이상 응답이나 요청 처리 예외를 이 코드로 묶는다. DB에는 정확한 HTTP 상태·예외 종류가 보존되어 있지 않고, 당시 서버 로그 조회 결과도 남아 있지 않아 구체적인 원인을 확정할 수 없다. 오류를 0건으로 바꾸거나 품질 기준에서 제외하지 않았다.

현재 코드의 정책 체크섬은 이 중단 실험의 고정값과 다르다. 현재 체크섬 차이는 이후 정책 변경이 포함된 상태의 비교이므로 중단 당시 정책 위반이 있었다는 증거로 소급 해석하지 않는다. 저장된 실제 제공 기록의 계획 hash는 모두 원래 계획과 일치하지만, 이것만으로 당시 실행 코드의 모든 버전까지 검증됐다고 주장하지 않는다. 원래 중단 직전 분석도 응답 오류 때문에 이미 품질 통과 상태가 아니었다.

## 후속 판단

- 이 A/A는 중단·미통과 상태로 보존하고 기존 분석을 후속 정식 A/B의 A/A 완료 조건으로 사용하지 않는다.
- 다음 계측 검증 전에 오류의 HTTP 상태·예외 종류·배포 버전과 개인정보를 제거한 로그를 보존하도록 설계해 같은 원인 미확정이 반복되지 않게 한다.
- 향후 A/A를 새로 실행한다면 기존 검토 스킬로 실제 모집·관찰 가능성을 재검토하고, 관찰창에 다른 정책 전환이 섞이지 않도록 계획한다. 이번 점검에서 새 실험을 시작하거나 기존 실험을 재개하지 않았다.

## 사용자 요청에 따른 기본 계측 부분 승인

2026-10-14 사용자 요청으로 위에서 확인된 **배정 균형·양군 동일 경험·응답/노출 기록 연결·응답 속도**를 ‘기본 계측 점검 완료’로 부분 승인했다. 근거는 분석 #521과 실제 제공/노출 연결 집계이며 `basic_quality_approval` 감사 이력에 승인 범위·보류 항목을 분리해 저장했다. 공통 어드민의 목록, 상세 진행 현황, 데이터 품질, 설계·이력에서 확인할 수 있다.

응답 오류 5건 원인, 168시간 관찰·클릭 검증, 수집 완전성은 보류다. 정식 A/A 전체 통과는 아니며 정식 A/B 시작 게이트를 충족하는 승인으로 사용되지 않는다. `quality_passed=false`, `decision_ready=false`, 중단 상태와 원래 계획·배정·분석·오류 기록을 유지한다. 기본 계측의 부분 승인이 과거 전체 품질 실패를 지우지 않는다.

부분 승인 점검표는 공통 상세의 **분석 결과** 탭에도 표시한다. 배정 균형, 동일 경험, 응답·노출 연결, 응답 속도, 오류 원인, 관찰·클릭 검증, 수집 완전성의 7개 항목을 확인값과 판정으로 제공한다. 성숙한 관찰 표본이 없어 효과를 계산할 수 없는 상태에서도 이미 완료한 계측 점검은 숨기지 않는다. 승인 근거의 고정값과 현재 분석의 관찰 완료 인원을 구분한다.
