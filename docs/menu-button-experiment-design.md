# 학식 버튼 A/B: 기존 유입 기반 계획 개정

검토일: 2026-10-14 KST. 시작 이후 개정한 **탐색 실험**이다. 기존 배정·시작 시각·원시 이벤트를 보존한다. 원래 기준율 1%와 각 군 1,767명(총 3,534명)은 과거 적격 유입을 확인하지 않은 가정이므로 운영 목표에서 폐기한다. 원래 값은 DB의 기존 필드와 `analysis_plan.original_plan`에 변경 이력으로만 보존한다.

## 실제 모집 가능성

개발자·QA·빈 식별자·미리보기 제외. 실제 `menu_button`의 `toss_promotion_menu_button` 노출 사용자 중복 제거. 전체 학식 사용자나 노출 이벤트 수를 모집 인원으로 사용하지 않는다. 분석 종료 경계는 10월 14일 00:00 KST 미포함이며 실험 시작 이전 데이터다.

| 기간 | 실제 노출 순사용자 | 노출 건수 |
| --- | ---: | ---: |
| 10/7~10/13, 7일 | 1,649 | 8,707 |
| 9/30~10/13, 14일 | 1,847 | 14,578 |
| 9/16~10/13, 28일 | 2,017 | 22,257 |

직전 네 주 각각의 순사용자는 오래된 순서로 1,235 / 830 / 1,316 / 1,649명이다. 휴일·요일 구성과 정책 변화가 있어 이 범위를 예측 보장으로 해석하지 않는다. 7일에서 28일로 늘려도 중복 제거 인원은 368명만 증가한다. 모집 기간에 일별 유입을 곱하는 계산은 부적절하다.

최근 7일 동일 버튼 문구와 선행 노출을 확인한 클릭 사용자는 55명, 참고 CTR은 3.34%다. 과거 노출 이벤트에는 기획전 ID가 없어 현재 실험의 ‘문구+목적지 일치’ 지표와 완전히 대조할 수 없다. 이를 관측 기준율의 확정값으로 쓰지 않는다. 직접 입력·출처 누락 클릭을 임의로 버튼 클릭에 포함하지 않는다.

재현: `python -m app.jobs.review_menu_button_history --end 2026-10-14`. 읽기 전용 반복 가능 스냅샷에서 집계하며 사용자 식별자는 출력하지 않는다.

## 실행 계획

- A: 🍱 자취생 먹을거 → 먹거리. B: 🔥 오늘의 핫딜 → 오늘 특가. 사용자 단위 50:50 고정 배정.
- 원래 시작 2026-10-14 01:12:08 KST부터 **7일**, 2026-10-21 01:12:08 KST 종료. 정확한 마이크로초는 DB의 시작+7일을 사용한다.
- 예상 약 **1,200명**, 참고 범위 **800~1,600명**. 통계적 필요 표본이나 모집 상한이 아니다. 1,200명에 먼저 도달해도 조기 종료하지 않는다. 미달해도 p값에 따라 연장하지 않는다.
- 주지표는 고정 기간 내 실제 노출 사용자 중 그 이후 문구·목적지가 일치하는 클릭 사용자 비율. 종료 직전 유입자의 관찰 시간이 짧은 누적 지표이며 개인별 24시간 지표로 해석하지 않는다.
- 마감 이후 배정·실험 이벤트 기록을 차단하고 완료 처리한다. 무유입 상태도 운영 모니터가 15분 이내 상태를 반영하며 어드민 조회 시에도 정리한다. 기본 버튼은 오늘의 핫딜이다. 기존 카드 실험 상태는 변경하지 않는다.
- 분석은 양측 Fisher 정확검정 및 Newcombe-Wilson 95% CI. 원래 정규근사 분석도 개정했으므로 확증 검정이 아닌 사후 탐색으로만 보고한다. 관측 차이, CI, 실제 분모, 계측 한계를 함께 표시하며 **자동 승자 판정은 하지 않는다**.
- CI가 넓거나 인원 부족, SRM p<0.001, 출처 전달 미확인, 중단/누락이 있으면 판단 보류. 의미 있는 개선 여부는 CI와 운영 효과를 함께 검토하며 탐색 결과를 구매 전환 또는 순수 문구 효과로 해석하지 않는다.
- 안전성: 기존 식단/공유 버튼 기능과 응답 오류를 확인한다. 클릭 추적 누락·응답 오류 발생 시 원인 점검 후 운영 판단하며 실험 결과를 확정하지 않는다. 기존 카드 실험의 자동 오류 경보는 유지한다.

## 작은 차이를 검출할 수 있는가

참고율 55/1,649를 가정한 양측 Fisher p<0.05 검정력. 각 군 동일 표본에서 두 독립 이항분포를 열거하고 양쪽 꼬리 각 1e-9 미만을 생략했다. 무작위 시뮬레이션이 아니므로 시드가 없다. 과거 참고율의 불확실성과 동시 실험 상호작용까지 반영한 보장값은 아니다.

| 총 인원 | +1%p | +2%p | +2.5%p | +3%p |
| --- | ---: | ---: | ---: | ---: |
| 1,200 | 11.8% | 35.1% | 49.8% | 64.1% |
| 1,600 | 14.8% | 45.6% | 62.8% | 77.3% |

재현: `python -m app.jobs.review_menu_button_power`. 1,200명은 작은 개선을 입증하기에 부족하다. 대규모 표본을 약속하는 대신 큰 변화의 방향과 계측을 탐색한다. 유의하지 않다는 이유로 ‘두 버튼 효과가 같다’고 결론 내리지 않는다.

## 동시 실험과 개정 이력

‘학식 저가 먹거리 24시간 탐색 A/B’는 기존 계획과 배정을 그대로 유지한다. 두 실험은 독립 배정하지만 같은 학식 흐름의 상호작용은 검증되지 않았다. 작은 표본을 4개 군으로 나눠 별도 유의성 검정을 하지 않는다. 카드 실험의 기존 중단·복구 기록도 유지한다.

개정 적용은 `python -m app.jobs.amend_menu_button_plan`으로 한 번만 수행한다. 실행 중인 지정 버튼 실험만 수정하며 원래 계획·시작·배정·상태는 보존한다. 변경 시각과 이유는 analysis_plan에 기록한다. 이 개정은 이미 결과가 노출된 실험을 사전 계획된 실험으로 바꾸지 않는다.

기준율 민감도도 확인했다. 총 1,200명에서 기준율 2%이면 +1%p 검정력 15.4%, +3%p 78.4%; 기준율 5%이면 각각 9.6%, 51.9%다. 어느 경우에도 +1%p를 안정적으로 판별하기 어렵다. 재현 시 `--baseline 0.02` 또는 `--baseline 0.05 --total 1200 --delta 0.01 0.03` 옵션을 사용한다.

## 적용 검증

2026-10-14 운영 계획 개정과 백엔드·실험 모니터 반영을 완료했다. 관련 16개 테스트(격리 임시 스키마에서 마감 이후 배정/클릭 차단, 다른 실험 상태·배정 보존, 탐색 자동 승자 차단, 통계 교차 검증 포함)가 통과했다. 실제 공통 어드민을 데스크톱 1,440px·모바일 390px에서 목록·모든 상세 탭·새로고침·직접 주소 재진입까지 검증했고, 예상 모집 및 마감·사후 개정 표시도 확인했다. 배포 후 무결성 검사에서 두 실험 모두 실행 중이고 기존 카드 실험의 고정 정책이 일치했다.

예상 1,200명은 직전 네 주 평균 1,257.5명을 둥글게 잡은 운영 참고치다. 통계 모형의 예측값·하한·신뢰구간이 아니다. 어드민 목록에는 실제 종료 조건인 ‘7일 고정 모집’과 참고 범위 ‘예상 800~1,600명’을 표시하며, 상세 설계에서 대표값과 근거를 함께 설명한다.
